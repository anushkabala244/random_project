# Inventory Management System

## About the Project
The Inventory Management System is a web-based application designed to manage products, monitor stock levels and maintain inventory records.

## Features
- Dashboard with inventory statistics
- Add, edit and delete products
- Search products
- Filter products by category and stock status
- Update stock quantities
- Low stock alerts
- Calculate total inventory value
- Export inventory data as CSV
- Store data using browser local storage

## Technologies Used
- HTML
- CSS
- JavaScript
- Browser Local Storage

## How to Run
1. Download or clone the repository.
2. Open the inventory-management folder in VS Code.
3. Open index.html using Live Server.
4. Manage products through the dashboard.
